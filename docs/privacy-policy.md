# OpenList privacy policy

Last updated: 2026-11-17

OpenList is a Chrome extension. It opens a list of URLs as tabs, and it copies the titles and addresses of your open tabs to your clipboard.

## What OpenList collects

OpenList does not collect personal data. It does not track your browsing. It does not send any data to a server. All work happens in your browser.

## What OpenList reads

- **Your open tabs.** OpenList reads the title and address of your open tabs to fill the list, to find the title of each URL you copy, and to skip a URL that is already open. It uses this data only on your computer.
- **Your clipboard, only if you allow it.** If you press "Turn on clipboard detection" and grant the permission, OpenList reads the clipboard text when you open the popup. It looks for web addresses in that text. If the text holds fewer than two web addresses, OpenList drops it at once. OpenList never stores, logs, or sends the clipboard text. The shortcut and the toolbar item never read the clipboard.

## What OpenList stores

OpenList stores settings and counters in your browser: the copy format you chose, the totals in Details (success rate, tabs opened, errors), the start time of the browser session, and whether you dismissed the clipboard button. These values never hold a URL, a title, or clipboard text.

## What OpenList writes

When you press Copy, use the keyboard shortcut, or use the toolbar menu item, OpenList writes the titles and addresses of the tabs you chose to your clipboard.

## Remote code

OpenList does not load or run code from a remote server.
