## Name

OpenList

## Summary (91 of 132 characters)

Open a list of URLs as tabs, or copy your open tabs as Markdown, CSV, JSON, HTML, and more.

## Category and language

Productivity. English.

## Description

OpenList does two jobs with one list of URLs.

**Open a list.** Paste URLs, or any text that holds web addresses (Markdown, HTML, CSV, JSON, plain lines), and open them all as tabs. Lines that are not addresses become Google searches. OpenList skips pages you already have open, opens up to 20 tabs at a time, and keeps the rest of the list for the next click.

**Copy your tabs.** The list starts with the tabs of your window. Choose the format and press Copy: URL, Title, Title & URL, Markdown, BBCode, HTML, Link, CSV, JSON, or HTML table. Pick selected tabs, this tab, this window, or all windows. A keyboard shortcut (Alt+Shift+C) and a toolbar menu item copy this window's tabs without opening the popup.

**Defaults that follow you.** OpenList picks selected tabs when you have highlighted more than one, remembers your last format, and can fill the list from a copied list of URLs if you allow clipboard detection.

**Private.** OpenList collects no personal data and sends nothing to any server. It reads the clipboard only if you turn clipboard detection on, only to find web addresses, and it never keeps that text.
